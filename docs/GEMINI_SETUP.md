# ملاحظة عن Gemini

تكامل Gemini السابق غير مستخدم في النسخة المحلية الحالية. التشغيل الفعلي يقرأ الكتب من `data/knowledge` ويستدعي OpenCode Zen من خادم Vite المحلي.

احتُفظ بكود Supabase وGemini داخل مجلد `supabase` كمرجع لمرحلة مستقبلية فقط، ويمكن حذفه أو تحديثه عندما نقرر طريقة الاستضافة النهائية.
