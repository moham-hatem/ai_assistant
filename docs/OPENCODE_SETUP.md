# إعداد OpenCode Zen محليًا

## إنشاء ملف الإعداد

انسخ `.env.example` إلى `.env.local` ثم اضبط:

```env
OPENCODE_API_KEY=ضع-المفتاح-هنا
OPENCODE_MODEL=deepseek-v4-flash-free
OPENCODE_API_ENDPOINT=https://opencode.ai/zen/v1/chat/completions
KNOWLEDGE_DIRECTORY=data/knowledge
KNOWLEDGE_MATCH_COUNT=6
```

لا تضع المفتاح في الشات أو في ملفات `src` أو في أي متغير يبدأ بـ`VITE_`.

## إضافة الكتب

يمكن رفع المحتوى المراجع من تبويب «الكتب» بصيغ TXT أو Markdown أو PDF أو DOCX. ويمكن أيضًا وضع نص عادي أو Markdown يدويًا داخل:

```text
data/knowledge/
```

يمكن إنشاء مجلدات فرعية لتنظيم المواد. يقسم الخادم الملفات إلى مقاطع تلقائيًا عند كل سؤال، لذلك تظهر تعديلات الملفات مباشرة دون استيراد أو قاعدة بيانات.

لا تضف نصًا غير موثوق أو تعليمات تشغيلية إلى مجلد المعرفة، لأن كل ملف `.txt` أو `.md` داخله يُعامل كمصدر تعليمي معتمد.

## التشغيل

```bash
npm run dev
```

إذا كان المفتاح أو الكتب غير موجودين، ستعرض الواجهة رسالة إعداد واضحة بدل إرسال طلب غير موثق إلى الموديل.

## الخصوصية

الملفات تبقى محليًا، لكن المقاطع المطابقة للسؤال تُرسل مع السؤال إلى OpenCode Zen. الموديل `deepseek-v4-flash-free` مجاني لفترة محدودة، وتوضح OpenCode أن البيانات المجمعة خلال الفترة المجانية قد تُستخدم لتحسينه. لا تستخدم بيانات شخصية أو سرية.
